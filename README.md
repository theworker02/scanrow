# scanrow

Scan encode/decode helpers for row payloads in pipelines.

**Site:** https://theworker02.github.io/scanrow/

## Install / run

```bash
git clone https://github.com/theworker02/scanrow.git
cd scanrow
node src/cli.js
node --test
```
